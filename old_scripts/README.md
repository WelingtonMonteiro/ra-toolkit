# old_scripts

Frozen copies of the userscript from before it was split into modules.

`RA_Toolkit.v2.9.0-monolith.user.js` is the last single-file version — the same
code that now lives in `src/`, before the split. It is kept for reference and
for bisecting behaviour differences; it is not built, tested or published.

The published script is built from `src/` into `dist/RA_Toolkit.user.js`.
