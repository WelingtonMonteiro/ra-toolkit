Welcome to the RA Toolkit Wiki! Here you'll find step-by-step instructions for every feature.

## 🚀 Quick Start

1. **[Install Tampermonkey](Getting-Started#step-1--install-tampermonkey)** in your browser
2. **[Install RA Toolkit](Getting-Started#step-2--install-ra-toolkit)** with one click
3. **[Set up your API key](Getting-Started#step-3--set-up-your-api-key)** to unlock all features
4. **[Configure settings](Settings-Panel)** to customize your experience

## 📚 Features

### Profile Enhancements
- **[Player Insights Dashboard](Player-Insights-Dashboard)** — Stats, streaks, rarest achievements, and "Almost There" tracker
- **[Activity Timeline](Activity-Timeline)** — GitHub-style heatmap of your daily activity
- **[Enhanced User Stats](Enhanced-User-Stats)** — Modern card-style stats replacing the native section
- **[Progression Status Dashboard](Progression-Status-Dashboard)** — Charts and interactive visualizations
- **[Profile Pagination](Profile-Pagination)** — Paginated "Last Games Played" with expandable badges
- **[Game Awards Tabs](Game-Awards)** — Mastered & Beaten tabs in the sidebar

### Game Page Features
- **[ROM Search](ROM-Search)** — Multi-source ROM finder with hash verification
- **[Achievement Rarity Indicator](Achievement-Rarity)** — Color-coded rarity badges
- **[Achievement Translation](Translation)** — Translate achievements to your language
- **[Speedrun.com Integration](Speedrun-Integration)** — World records and gameplay videos

### Site-Wide Features
- **[User Wall Enhancements](Wall-Enhancements)** — Linkify, YouTube embeds, image previews (also on achievement comments)
- **[Achievement & Comment Translation](Translation)** — Translate achievements, wall comments, and achievement comments
- **[Most Mastered Tab](Most-Mastered)** — Browse games ranked by player count
- **[Achievements Dropdown](Achievements-Dropdown)** — Restored navigation menu
- **[Extras](Extras)** — Custom backgrounds, accent colors, mobile support
